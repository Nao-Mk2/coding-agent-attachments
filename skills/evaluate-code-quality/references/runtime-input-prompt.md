# Runtime input prompt

Use this prompt when invoking the skill from an agent, CI workflow, or PR comment bot.

```md
以下のPull Requestについて、実装後の一次評価をしてください。

目的は、レビュー担当者がPR全体を頭から読む前に、影響範囲、品質リスク、追加すべきテスト、人間が重点的に見る箇所を把握できるようにすることです。

あなたは承認・却下を判断しないでください。レビューを軽くするためのリスク整理と確認観点の提示に集中してください。

## 入力

### PRタイトル
{{PR_TITLE}}

### PR本文
{{PR_BODY}}

### 変更ファイル一覧
{{CHANGED_FILES}}

### 差分
{{DIFF}}

### テスト結果
{{TEST_RESULTS}}

### 静的解析・セキュリティ検査結果
{{ANALYSIS_RESULTS}}

上記の結果はCIから提供されたものだけを使用してください。ローカルでテスト、lint、ビルド、スキャンを再実行しないでください。

### 関連Issue・仕様
{{RELATED_CONTEXT}}

## 評価してほしいこと

1. 全PR共通のコア評価として、変更概要、影響範囲、失敗しそうなケース、テストの妥当性、人間が重点的に見る箇所、不確実性、リスク分類を整理する
2. 差分に具体的な根拠がある品質特性を0〜2件選ぶ
3. 選んだ品質特性だけについて、選定理由、影響理由、確認方法を書く
4. 品質特性を上限まで埋めるために、根拠の弱い特性を選ばない

## 制約

- diffにない実装を推測しすぎない
- 不明な点は不明と書く
- テストで確認できることと、人間が判断すべきことを分ける
- 一般論ではなく、このPRに即して書く
- 指摘は重要度順に並べる
- 些細なスタイル指摘はしない
- コア評価と、最大2件の品質特性評価を混同・重複させない
```
